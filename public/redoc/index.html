License: Apache-2.0

Five native Prometheus 3.5.0 POST interfaces. The hosted server is a replay sandbox, not a PromQL engine. Use the exact request examples. Basic credentials labreader / prometheus-lab-demo are public demo credentials. Native upstream captures were taken on 127.0.0.1:9095 without authentication; BasicAuth belongs to the laboratory gateway. Gateway 401 is JSON. Native 503 is documented but was not fault-injected.
