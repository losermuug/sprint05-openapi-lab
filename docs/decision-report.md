# Swagger UI болон Redoc харьцуулсан шийдвэр

Prometheus төслийн баримтад Swagger UI болон Redoc хоёрыг зэрэг ашиглахаар сонгов. Swagger UI нь authentication тохируулж, хүсэлт илгээж, HTTP төлөв болон JSON хариуг шалгах боломжтой учраас хөгжүүлэгчийн sandbox ажиллагаанд тохиромжтой. Redoc нь навигаци, тайлбар, жишээг гурван баганад байрлуулж, endpoint хайх болон schema унших ажлыг хөнгөвчилдөг. Манай хувилбарт Redoc хайлттай, Swagger UI нь endpoint шүүлтүүртэй. Хайлтын миллисекундийн хурдыг хэмжээгүй тул хурдан гэсэн тоон дүгнэлт хийгээгүй. Redoc Community нь Try It Out агуулаагүй учраас хүсэлтийг Swagger UI дээр шалгана. Иймээс нийтэд уншуулах үндсэн лавлагаанд Redoc, хэрэгжүүлэлт турших орчинд Swagger UI сонгож, хоёуланг нэг OpenAPI файлаас үүсгэнэ. Ингэснээр баримтын хувилбарууд зөрөх эрсдэл буурна.
